FAQ

The important bits,
without the fine-print maze.

SquashAI is still an actively developed product, so the website focuses on the architecture and experience rather than pretending every feature is finished.

Does SquashAI use online AI?

No. The current product direction is offline-only local inference. There is no online AI fallback.

Can I choose a lower model than the recommendation?

Yes. The recommendation is only a suggestion. Any model that passes the device's supported RAM and storage thresholds can remain selectable.

Can I install all six models?

The app is designed to keep one completed local model at a time. Switching models replaces the active model rather than keeping all six.

What happens if my phone cannot run a model?

That tier is shown as unavailable and the app can explain the device requirement instead of allowing an unsafe download.

Is SquashAI only for Android?

The current MVP is being validated on Android first. The local runtime architecture is being kept portable for future iOS work.

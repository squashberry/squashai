# SquashAI

Official SquashAI product website.

SquashAI is a private, offline AI created by Squashberry. The website explains the local-model architecture, one-model-at-a-time storage strategy, device compatibility model, and mobile chat experience.

## Live site

https://squashberry.github.io/squashai/

## Repository

https://github.com/squashberry/squashai

## Deployment

The site is static HTML/CSS/JS and is published with GitHub Pages from the `main` branch.

## Branding

The included SVG logo is the web representation of the SquashAI speech-bubble app mark.
